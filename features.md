# RENTSPOT Features

## User
- Register / Login / Logout
- Browse stadiums
- Filter by sport, city, price
- View stadium details
- Select date and time slot
- Create reservation
- Pay online
- View my reservations
- Cancel pending reservation
- Add review after completed reservation

## Admin
- Login
- Manage sports
- Manage stadiums and images
- Manage reservations
- Confirm / cancel / complete reservations
- Manage payments
- Manage users
- Manage reviews
- View dashboard statistics
